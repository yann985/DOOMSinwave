#   description  : texte affiché dans le choix d'arène
#   map          : carte (déclarée dans MAPINFO, fichier maps/NOM.wad)
#   waves        : fichier des cercles de cette arène
#   enemy_health : multiplicateur de vie des ennemis
#   enemy_speed  : multiplicateur de vitesse des ennemis
#   spawn_rate   : multiplicateur du rythme d'apparition (2 = deux fois plus souvent)
#   reward       : multiplicateur des indulgences gagnées
#   spawn        : player (autour du joueur, par défaut) ou points (points d'apparition de la carte)
