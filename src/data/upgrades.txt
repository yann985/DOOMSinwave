# Choix proposés à chaque montée de niveau, en trois familles :
#   - les vertus : un petit bonus, et l'âme se purifie ;
#   - les neutres : un bonus moyen, sans défaut, et l'âme ne bouge pas ;
#   - les péchés : un gros bonus avec un défaut, et l'âme se corrompt.
# La corruption fait pencher la balance de l'âme (data/soul.txt) : à chaque palier
# franchi, d'un côté ou de l'autre, la partie change. Plus l'âme penche, plus les
# neutres sont rares (offer_neutral_chance, data/progression.txt).
#
#   name        : nom affiché
#   description : texte affiché sous le nom
#   kind        : virtue, neutral ou sin
#   corruption  : corruption ajoutée (négative : la vertu purifie ; un neutre n'en a pas)
#   effects     : liste d'effets « type:valeur », séparés par des virgules
#                 types : maxhealth, heal, armor, damage, vulnerability, speed,
#                         regen, magnet, xpgain, aura, infiniteammo,
#                         give (give:Classe ou give:Classe:nombre)
#   max         : nombre de fois où il peut être choisi pendant une run
