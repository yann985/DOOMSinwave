# Systèmes de jeu créés au lancement, dans cet ordre.
#
# Chaque système ne dépend que des services (bus, données, sauvegarde) et ne
# connaît aucun autre système. On peut donc :
#   - le désactiver : enabled = false (le reste du jeu continue de tourner) ;
#   - le remplacer  : class = une autre classe qui hérite de Sinwave_System.
#
# Le journal (debug) est en premier pour voir les événements dans l'ordre exact
# de leur publication.
