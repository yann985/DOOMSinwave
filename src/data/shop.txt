# Boutique des indulgences : achats permanents, entre les runs.
# Chaque niveau acheté applique ses effets au début de chaque run.
#
#   name         : nom affiché
#   description  : texte affiché
#   category     : weapon (arme) ou blessing (amélioration permanente)
#   price        : prix du premier niveau, en indulgences
#   price_growth : multiplicateur du prix à chaque niveau (1.5 = +50 %)
#   max          : nombre de niveaux
#   effects      : mêmes effets que data/upgrades.txt

# --- Armes : on commence chaque run avec -------------------------------------
