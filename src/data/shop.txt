# Boutique des indulgences : achats permanents, entre les runs.
# Chaque niveau acheté applique ses effets au début de chaque run.
#
# Quatre rayons (onglets), ouverts selon le Jugement de l'âme (data/judgement.txt) :
#   (pas de side)       Armurerie  : toujours ouverte
#   side = grace        Grâce      : le bien protège (vie, défense, soins)
#   side = neutral      Équilibre  : objets compensés, un peu des deux
#   side = corruption   Corruption : le mal frappe (dégâts, vitesse)
#   tier = 1, 2 ou 3    palier du Jugement demandé (Grâce ou Corruption) : plus il
#                       est haut, meilleur est l'objet
# Un article verrouillé reste achetable s'il a déjà été acheté une fois.
#
#   name         : nom affiché
#   description  : texte affiché
#   category     : weapon (arme) ou blessing (amélioration permanente)
#   price        : prix du premier niveau, en indulgences
#   price_growth : multiplicateur du prix à chaque niveau (1.5 = +50 %)
#   max          : nombre de niveaux
#   effects      : mêmes effets que data/upgrades.txt
